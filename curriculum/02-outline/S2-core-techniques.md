# S2 — Core techniques (*Kerntechnieken*), 260 h

Phase 2 outline for stage S2. The conventions are in [`../02-curriculum-outline.md`](../02-curriculum-outline.md#conventions);
the purpose and exit gate are in [Phase 1 §6.2](../01-vision-architecture.md#62-stage-profiles).

**Stage question:** can I carry out the core professional techniques across the main ingredient groups?
**Entry:** `MS-S1` passed.

Course order:
1. `SCI-2` first: its science is used by everything after it.
2. Then `HEA-2`, `KNF-2` and `STK-2`.
3. Then `SAU-2`, followed by the protein courses `POU-2`, `MEA-2` and `FSH-2`.
4. `LEG-2` follows `SAU-2` (cheese sauce builds on *béchamel*).
5. `BAK-2` and `BRD-2` only need `SCI-2`, so they can run in parallel with the savoury courses.
